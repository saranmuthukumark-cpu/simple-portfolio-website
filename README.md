Simple Portfolio Website

A clean and responsive personal portfolio website built using only HTML and CSS.
This project is designed to showcase skills, projects, and contact details with a minimal and modern layout.

🚀 Features

Fully responsive design for desktop, tablet, and mobile

Clean and simple code structure

Easy to customize with your own details and images

No JavaScript – purely HTML & CSS

💻 How to Use

Clone the repository

git clone https://github.com/your-username/portfolio-website.git


Open the project

Go to the project folder

Open index.html in any browser to view the website

🖌️ Customization

Replace the content inside index.html with your own name, projects, and contact details.

Update colors, fonts, and layout inside style.css as needed.
